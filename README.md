# PresuPladur

App para hacer presupuestos de pladur desde el móvil: PDF, envío por WhatsApp, fotos de la obra, dictado por voz, histórico y margen de cada trabajo.

Se abre en https://ivansaborido.github.io/presupladur/ y se instala desde el navegador con "Añadir a pantalla de inicio".

Los presupuestos se guardan en el móvil de quien usa la app. Este repositorio solo contiene la aplicación.
